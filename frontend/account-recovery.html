A way back in.

Save a recovery code while you can sign in. If you forget your password, use the code once to regain access.

Save a recovery code

Use your current password to create or replace your code. Keep it in your password manager or another private place. Anyone with it can reset your password.

This replaces any earlier code. It stays valid until used or replaced. We cannot show it again.

Reset your password

Enter the recovery code you saved. Resetting your password signs out your previous sessions and removes their notification subscriptions.

Without a saved code or your current password, self-service recovery is unavailable. Email recovery is not enabled.
